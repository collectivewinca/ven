# json-render Demo

**Part of [collectivewinca/miny-ven](https://github.com/collectivewinca/miny-ven)**

Generative UI playground using Vercel's [json-render](https://github.com/vercel-labs/json-render) framework with DeepSeek/OpenRouter integration.

## Quick Start

```bash
cd experiments/json-render-demo
npm install
npm run dev
```

Open http://localhost:3000 and enter your API key.

## Related to miny-ven

This experiment explores whether AI-generated UIs could enhance the music news experience. See the main [miny-ven repo](https://github.com/collectivewinca/miny-ven) for the production app.
